# 🎵 Vibe - Professional Music Player

A full-featured music player application with a Node.js backend and modern web interface.

## Features

- 🎵 Complete music player with play/pause, next/previous
- 📊 Progress bar with seeking
- 🔀 Shuffle and repeat modes
- ❤️ Favorite tracks (like system)
- 📤 Upload new tracks
- 🎚️ Volume control
- 📋 Recent played tracking
- 🎨 Modern, responsive UI
- ⌨️ Keyboard shortcuts (Space, Arrow keys)
